# maravoa-social

Content for the Maravoa Instagram account, [@maravoasalon](https://www.instagram.com/maravoasalon/).
Maravoa is salon software for independent stylists, booth renters and small salons: [maravoa.com](https://www.maravoa.com/).

Everything here is meant to be public. Images are real Maravoa screens showing demo data only, never a real client.

- `instagram-2026-11/plan.md`: the launch plan (audience, pillars, cadence, measurement).
- `instagram-2026-11/posts/`: one file per post with caption, hashtags, alt text and day.
- `instagram-2026-11/visuals/`: the images, at Instagram sizes. The scheduler pulls them by their raw GitHub URL, so do not rename or move a file that is already scheduled.
- Later weeks go in a new folder per batch, `instagram-YYYY-MM-DD/`.

Posts are scheduled through Metricool and go out only after Marshall approves each weekly batch.
No GitHub Actions run in this repo.
